📖 Hike プログラミング例題・演習集 (全 9 演習)

        
      

      


        

          

            
演習 1: 1 から N までの総和計算 初級

演習 2: 文字列リテラルとポインタ操作 初中級

            
メモリ上の UTF-8/ASCII 文字コード配列とポインタ `*byte` 参照を学びます。

          

          
        


        

          

            
演習 3: 配列要素の最大値探索 中級

演習 4: ユークリッドの互除法 (最大公約数) 中級

演習 5: 簡易的なバブルソート 中上級

            
隣接要素の比較と一時変数 `temp` による配列スワップをメモリ上で観察します。

          

          
        


        

          

            
演習 6: XOR データ暗号化と復号 中上級

            
ビット演算 `^` の可逆性と暗号データ変化のステップ追跡です。

          

          
        


        

          

            
演習 7: 再帰関数 (フィボナッチ数列) 上級

            
関数の自己呼び出し、コールスタック、スタックフレームの伝搬を学びます。

          

          
        


        

          

            
演習 8: Web API HTTP レスポンスパース 上級

            
構造体 `struct` のメモリ配置と仮想ネットワークノード通信の連携です。
